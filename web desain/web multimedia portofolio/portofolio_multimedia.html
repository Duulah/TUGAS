Tentang & Minat

Portofolio multimedia ini jadi tempat saya bereksperimen membuat tampilan web yang interaktif, rapi, dan responsif. Bagi saya, membuat web bukan hanya soal baris kode yang berjalan, tapi juga soal membangun pengalaman pengguna yang seru dan nyaman. Minat saya tidak berhenti di web saja, saya juga suka mengulik mekanika gim, fitur-fitur canggih, dan estetika visual. Supaya pikiran tetap segar dan ide terus mengalir, saya biasa melatih fokus dengan mencari inspirasi dari anime dan gim. Kombinasi antara logika, imajinasi, dan rasa penasaran inilah yang selalu mendorong saya untuk terus berkarya.

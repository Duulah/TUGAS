Pengenalan HTML

HTML (HyperText Markup Language) adalah bahasa markup standar untuk membuat halaman web.

Fitur HTML

  • Mendefinisikan struktur halaman web
  • Menggunakan elemen untuk menandai konten
  • Elemen diwakili oleh tag

Contoh Format Teks

Kita dapat membuat teks tebal, miring, subscript, dan superscript.

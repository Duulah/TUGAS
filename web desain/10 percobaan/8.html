Berbagai Cara Memformat Teks dalam HTML

Ini adalah teks tebal (bold) menggunakan tag <b>.

Ini adalah teks penting (strong) menggunakan tag <strong>.

Ini adalah teks miring (italic) menggunakan tag <i>.

Ini adalah teks penekanan (emphasized) menggunakan tag <em>.

Ini adalah teks ditandai (marked) menggunakan tag <mark>.

Ini adalah teks kecil (small) menggunakan tag <small>.

Ini adalah teks tercoret (deleted) menggunakan tag <del>.

Ini adalah teks disisipkan (inserted) menggunakan tag <ins>.

Ini adalah teks subscript menggunakan tag <sub>.

Ini adalah teks superscript menggunakan tag <sup>.

Ini adalah teks kode komputer (code) menggunakan tag <code>.

Ini adalah teks dengan HTML singkatan menggunakan tag <abbr>.

Ini adalah teks dengan kutipan pendek (quotation) menggunakan tag <q>.
